개인정보처리방침

홈 · 개인정보처리방침 · 서비스 약관

이 방침은 "받을돈 업로더"(이하 "도구")에 적용됩니다.

1. 누가 사용하나요

도구는 받을돈 채널 운영자 본인만 사용하는 내부 도구입니다. 다른 사람의 구글·유튜브 계정에는 연결하지 않습니다.

2. 어떤 정보를 사용하나요

  • 운영자 본인 유튜브 채널에 대한 접근 권한(Google OAuth 토큰): 영상 업로드, 채널 소개글 관리, 채널·영상 통계 조회에만 사용합니다.
  • 운영자 본인 채널의 공개 통계(조회수, 좋아요 수, 구독자 수 등)

시청자나 다른 이용자의 개인정보는 수집하지 않습니다.

3. 어떻게 보관하나요

접근 권한 정보는 운영자의 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자와 공유하거나 판매하지 않습니다.

4. Google API 사용

도구가 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 준수합니다.

5. 권한 철회

운영자는 언제든지 Google 계정 권한 페이지에서 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 권한 정보는 더 이상 쓸 수 없습니다.
